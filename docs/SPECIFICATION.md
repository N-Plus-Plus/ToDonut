# Product specification

> Repository instruction precedence: [AGENTS.md](../AGENTS.md) governs this document.

ToDonut is an owner-operated, single-user task manager with an optional Bakery. The app provides Tasks, Projects, Areas, reference Lists, Settings Schedules, configurable Statuses, Priorities, Tags and Quantifiers, history, Trash and desktop full-fidelity export. Today is the default destination. [User experience](USER_EXPERIENCE.md) owns accepted journeys and [contracts](CONTRACTS.md) owns domain rules.

The Bakery turns productivity rewards and purchased supplies into products and deterministic market sales; [Bakery](BAKERY.md) owns actual mechanics. Production is online-first with Supabase owner authentication. The development localStorage provider is not an offline production mode. Existing saved hierarchy remains supported while Child Task creation and parent assignment and Must Do Today are disabled.

Offline/PWA, JSON import, notifications, calendar, collaboration and unimplemented trusted-device/TOTP/lockout features are not established as current capabilities. Historical proposals do not authorise implementation.
