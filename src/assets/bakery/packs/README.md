# Bakery Basic Pack artwork

Place optional transparent PNG artwork here for the final Basic Pack row in each shop:

- `basic.png` (Starting shop)
- `common.png`
- `filling.png`
- `artisan.png`
- `premium.png`

Each image is displayed at the standard 40px Bakery row-art size. Until supplied, the registered package fallback is shown.
